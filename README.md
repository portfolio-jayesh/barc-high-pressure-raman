# High-pressure Raman spectroscopy of Na₂Cu₂TeO₆

Jayesh Jadhav · Summer research at BARC, Mumbai · Guide: Dr. Subodha Sahoo

[Internship report](reports/barc-summer-project.pdf) · [Pressure-dependent Raman spectra](figures/pressure-dependent-raman-spectra.jpg)

Diamond-anvil-cell Raman measurements extended to approximately 12 GPa. Changes near 7 GPa suggested a possible phase transition. The report discusses the need for structural measurements to test that interpretation. The image is Figure 1 extracted from the report.
